## ✨ 四大核心特色

### 🗺️ 中国地图点亮

> 34个省级行政区 · 391个城市 · 真实地理坐标

- 基于微信原生 map 组件，每个省份标注在真实经纬度上
- **已打卡省份**用粉色标记 + ✓号标注，气泡显示「N/M 城」进度
- 地图下方**省份标签栏**横向滚动展示所有已点亮省份
- 每个城市拥有**真实必打卡地标**（如故宫/兵马俑/九寨沟等）

### 🃏 抽卡收集系统

> 探索城市解锁专属角色卡 · SSR / UR 稀有度 · 抽卡动画

- 每个省份首次点亮时触发**抽卡动画**（卡片翻转、光效粒子）
- 角色卡分为 N / R / SR / SSR / UR 五个稀有度等级
- 每张卡拥有**地域主题插画**和个性描述
- 卡组图鉴展示收集进度，支持按稀有度筛选

### 🏆 成就徽章体系

> 探索 / 收集 / 社交 / 特殊 四大类 · 30+ 成就

- **探索类**：点亮 1/5/10/20/50/100 座城市 & 首个省份成就
- **收集类**：获得 SSR/UR 卡、收集 N 张角色卡、集齐全部稀有度
- **社交类**：分享地图、记录笔记、上传照片数量
- **特殊类**：夜猫子（凌晨打卡）、早鸟（清晨打卡）、闪电侠（单日多次）
- 成就解锁时**弹窗提示**，成就页面分门别类展示

### 👥 群组共享

> 邀请码机制 · 共享照片流 · 成员排行榜 · 数据同步

- **创建群组**：选择「朋友 / 情侣 / 家人」类型，获得 6 位邀请码
- **加入群组**：输入邀请码即秒加入，云端验证防重复
- **共享照片**：成员可上传旅行照片到群组，全员可见时间线
- **成员排行**：按点亮城市数自动排序，激励竞争与合作
- **云端同步**：每次进入群组页自动同步最新打卡/照片数据

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| 微信小程序原生框架 | WXML / WXSS / JavaScript / JSON |
| 微信云开发 CloudBase | 云函数 · 云数据库 · 云存储 |
| Node.js（云函数） | 登录鉴权 · 数据同步 · 群组管理 |
| 分包加载 | 3 个分包，主包优化至 1.4MB |
| 代码生成 WAV 音频 | 8bit PCM 纯代码合成，零外部依赖 |
| 本地缓存 Storage | 离线可用，用户数据持久化 |

## 🎯 项目亮点

- **📦 分包体积优化** — 主包 26MB → 1.4MB，PNG→JPG 节省 88%
- **🗺️ 391 个城市真实地标** — 覆盖全国每个角落，地标数据丰富准确
- **🃏 抽卡 + 成就双循环** — 游戏化设计让旅行打卡更有动力和目标感
- **👥 群组共享体系** — 邀请码 + 共享照片 + 成员排行，旅行不孤单
- **☁️ 全栈云开发** — 5 个云函数 + 云数据库，无需独立后端
- **🎵 代码生成音效** — 8bit PCM WAV 纯代码合成，无外部音频文件
- **📱 离线可用** — 本地 Storage 缓存，无网络也能正常使用
