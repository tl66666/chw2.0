# 城会玩2.0

城会玩2.0 是一款围绕“城市探索、旅行记录、角色卡收集、成就激励”设计的微信小程序。用户可以在地图上点亮去过或想去的城市，查看城市详情，收集具有地域特色的角色卡，并通过探索行为解锁成就，让旅行记录不只是相册，而是一个持续成长的城市图鉴。

## 项目信息

- 项目名称：城会玩2.0
- 项目类型：微信小程序
- 小程序 AppID：wx1bccd82d1adb0fa9
- 开发方式：原生微信小程序
- 后端与资源：微信云开发、云函数、云存储

## 核心功能

### 城市地图点亮

- 支持中国城市/省份维度的足迹点亮。
- 地图标记展示已探索城市，形成可视化旅行足迹。
- 城市详情页展示城市介绍、图片、探索状态与相关互动入口。

### 城市详情与旅行记录

- 每个城市拥有独立详情页，用于承载城市图片、介绍、解锁状态和探索内容。
- 支持将城市探索和个人旅行记忆结合，方便后续扩展照片、笔记和打卡记录。

### 角色卡收集

- 通过探索城市解锁角色卡。
- 角色卡包含稀有度、角色形象、名称和地域风格设定。
- 支持角色卡列表、筛选、详情查看和解锁反馈。

### 成就系统

- 根据探索城市数量、收集角色卡、社交互动等行为解锁成就。
- 成就分为探索、收集、社交、特殊等类型。
- 通过积分、进度条和完成状态给用户持续反馈。

### 云端资源管理

- 城市图片和角色卡图片体积较大，使用微信云存储管理，降低小程序主包压力。
- 通过云函数获取资源临时访问地址，避免本地资源过多导致上传限制。
- 对资源加载做了本地缓存和兜底处理，提升页面稳定性。

## 技术实现

- 原生微信小程序页面结构：WXML、WXSS、JavaScript、JSON。
- 使用分包管理角色卡、相册等页面，减少主包体积。
- 使用微信云开发完成登录、资源地址解析、数据同步等能力。
- 使用本地缓存保存用户探索状态、角色卡收集状态和成就进度。
- 对城市图片和角色卡图片进行云存储迁移，解决大图资源导致的包体限制问题。

## 云开发说明

项目使用微信云开发能力。首次导入项目后，需要在微信开发者工具中确认：

1. 小程序 AppID 为 `wx1bccd82d1adb0fa9`。
2. 云开发环境已开通并选择正确环境。
3. `cloudfunctions` 目录下的云函数已上传并部署。
4. 云存储中的 `cities/`、`cards/` 等目录资源存在，并且访问权限配置正确。

如果图片无法显示，优先检查云存储权限、云函数是否部署，以及资源 File ID 是否与代码配置一致。

## 本地运行

1. 使用微信开发者工具导入本目录。
2. 确认 AppID：`wx1bccd82d1adb0fa9`。
3. 在“云开发”中选择项目对应环境。
4. 上传并部署云函数。
5. 点击“编译”运行小程序。
