# 城会玩2.0

城会玩2.0 是一款围绕“城市探索、旅行足迹、角色卡收集、成就反馈”设计的微信小程序。项目把旅行记录做成地图点亮、城市详情、角色卡抽取、成就解锁和相册归档的组合体验，让用户的旅行足迹更有收集感和成长感。

## 核心功能

### 城市地图点亮

- 支持全国城市足迹记录。
- 用户可以在地图上点亮去过或想去的城市。
- 城市详情页展示城市信息、图片、探索状态和相关互动入口。

### 角色卡收集

- 探索城市后解锁具有地域特色的角色卡。
- 角色卡包含名称、稀有度、形象和描述。
- 支持角色卡列表、筛选、详情查看和解锁反馈。

### 成就系统

- 根据城市点亮、角色卡收集、相册记录等行为解锁成就。
- 成就分为探索、收集、社交、特殊等类型。
- 通过进度条、积分和完成状态给用户持续反馈。

### 相册与旅行记录

- 支持旅行照片归档和展示。
- 后续可继续扩展为城市笔记、路线记录和旅行愿望清单。

### 云存储资源管理

- 城市图片和角色卡图片体积较大，迁移到微信云存储。
- 通过云函数获取资源临时地址，降低小程序主包体积。
- 结合本地缓存优化图片加载体验。

## 技术实现

- 原生微信小程序：WXML、WXSS、JavaScript、JSON。
- 微信云开发：登录、数据同步、资源地址解析、云存储访问。
- 分包加载：角色卡、相册和扩展页面拆分到分包，降低主包压力。
- 本地缓存：保存用户探索状态、角色卡收集状态和成就进度。

2. 确认 AppID 为 `wx1bccd82d1adb0fa9`。
3. 在云开发面板选择项目对应环境。
4. 上传并部署 `cloudfunctions` 目录下的云函数。
5. 编译运行小程序。
